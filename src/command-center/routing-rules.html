Hello@ Forwarding
Reads everything arriving at hello@bpmsd.com and sends it to the right inbox
How it decides
1. Your rules run first. Every rule below is checked in order, top to bottom. The first one that matches wins and nothing else is looked at. Rules are instant, free, and do the same thing every single time.

2. Anything no rule matched goes to the AI, which follows the instructions at the bottom of this page and picks an inbox.

3. What happens next depends on how sure it is. Confident answers get forwarded automatically. Anything less sits in Needs a Human below, where you read it and add a rule so it never has to guess about that again.

Nothing is ever sent outside the company. The only addresses it can forward to are your own BPM inboxes. Newsletters and marketing are set aside on the unsubscribe list rather than unsubscribed automatically, so a person sees each link before clicking it.
